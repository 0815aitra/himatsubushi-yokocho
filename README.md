# ひまつぶし横丁

スマホとPCのブラウザで遊べる、8種類のミニゲーム集です。

## 収録ゲーム

- 記憶力チャレンジ
- 反射神経テスト
- ピッタリタイム
- 数字順タップ
- 色あて
- 暗算スピードバトル
- 数字パズル
- ブロック崩し

全ゲームに「やさしい・ふつう・むずかしい」の難易度と、端末内ランキングがあります。

## 遊ぶ

[公開版をブラウザで遊ぶ](https://himatsubushi-yokocho.moriso4798.chatgpt.site)

ローカルで遊ぶ場合は、ファイル一式をダウンロード・解凍して `index.html` を開いてください。
